# E2M Chauffage — site local

Ouvrir http://localhost:3000 quand le serveur est lancé.

Pour relancer : ouvrir un terminal dans ce dossier, puis exécuter `npm start`.
Aucune installation de dépendances nécessaire. Node.js suffit.

Les six pages statiques et les ressources sont dans `dist`. Les textes sont générés depuis `generate.mjs` avec `npm run build`. Le CSS et le JavaScript sont éditables directement dans `dist`.

Sources factuelles consultées : https://e2m-chauffage.com/ et ses pages chauffage-entretien, pompes-a-chaleur, energies-solaire, sanitaire et contactez-nous. La photo de maison provient d'Unsplash et est illustrative ; aucune attribution à une réalisation E2M n'est faite.

Les anciennes aides financières, certifications et données de performance n'ont pas été reprises. Le formulaire prépare un e-mail via la messagerie de l'utilisateur ; il n'envoie rien depuis un serveur.
